# Reader-facing terminology contract

Internal milestone codes are project bookkeeping, not scientific terminology.
They must not appear in the manuscript, supplementary narrative, publication
table labels, figure text or captions. Use the following stable names:

| Internal code | Reader-facing name |
| --- | --- |
| M7.2 | independent supporting-validation experiment |
| M7.3 | process-based integration benchmark |
| M7.3 evidence audit | multi-evidence integration audit |
| M7.3 age audit | topology-conditioned-age audit |
| M7.3 reaction audit | reaction-family recovery audit |
| M7.4 | competence-matched sheaf-versus-weighted-graph representation benchmark |
| M7.5 | local-first/global-fallback estimator diagnostic |

Short forms such as *representation benchmark* and *estimator diagnostic* may
be used after the full term has been introduced. Exact run identifiers, locked
artifact filenames and repository paths retain their original codes because
changing them would break provenance.
