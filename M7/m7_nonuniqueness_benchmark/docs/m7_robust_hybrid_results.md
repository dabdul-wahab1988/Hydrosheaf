# M7.5 robust/hybrid sheaf results

The two-stage protocol and both locks passed. Sixty-four development cases
selected all hyperparameters before a single 128-case locked-test execution.
All cases were generated by the unchanged independent M7.4 generator, and all
test truth was excluded from representation, calibration and threshold
selection.

## Primary result

| Contrast: robust hybrid minus edge-local | Difference | 95% CI | Gate |
|---|---:|---:|---|
| PR-AUC | +0.01997 | +0.00728 to +0.03244 | pass |
| Brier score | -0.00151 | -0.00419 to +0.00105 | fail |
| Log loss | +0.00333 | -0.00341 to +0.01009 | fail |

The full incremental claim failed. This is not an execution failure: the
workflow/provenance gate passed, but the estimator did not satisfy the frozen
three-outcome efficacy rule.

## Mechanism attribution

The development selection chose a local weight of 1.0 for both hybrid arms,
using global information only where a local endpoint residual was unavailable.
This hybridisation significantly improved the original global representation
on PR-AUC, Brier score and log loss. By contrast, leave-one-edge-out robust
downweighting worsened Brier score and log loss relative to the original global
estimator, and the robust hybrid worsened both calibration metrics relative to
the original hybrid. The M7.4 heterogeneous-affine loss is therefore partly a
local-information-loss problem, not principally an edge self-influence
problem.

## Scenario boundary

PR-AUC gains over the edge-local graph were supported for incompatible cycles
(+0.0437, 95% CI +0.0125 to +0.0751) and noisy/missing observations (+0.0335,
+0.0110 to +0.0559). Heterogeneous-affine PR-AUC did not improve, and log loss
was worse by +0.0251 (+0.0121 to +0.0373). Native maps beat the permuted-map
control on all three primary outcomes.

## Scientific decision

Retain M7.4 and M7.5 together. M7.4 identifies the representational value of
non-identity maps and global conflict localisation. M7.5 shows that a local-
first/global-fallback hybrid can recover ranking value where observations are
missing or relations conflict, but stronger LOO robustification is not an
excellent general estimator and does not earn overall-superiority status.
