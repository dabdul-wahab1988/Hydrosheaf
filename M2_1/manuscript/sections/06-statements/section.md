## 6. Statements

### Code and data availability

HydroSheaf source code, package metadata, tests and benchmark protocols are maintained in the project repository. The controlled-synthetic evidence is linked to a machine-readable provenance manifest containing the generating source revision, cryptographic source hashes and generator metadata. The real measurements are retained in the project field-data archive with their source-study citations and access conditions. A public repository URL or DOI was not assigned in this package, so the availability statement is complete for the working repository but not yet a public-release statement. No new field samples were collected for this manuscript.

### Ethics, competing interests and funding

The study used existing measurements and controlled synthetic data, with no new human or animal subject procedures. The authors declare no competing interests and no external funding for the software validation reported here unless stated in the final submission metadata.
