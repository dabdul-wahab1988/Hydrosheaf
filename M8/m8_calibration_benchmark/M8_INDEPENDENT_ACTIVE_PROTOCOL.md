# M8 independent-model and active-learning protocol

Run ID: `RUN-M8-INDEPENDENT-20260728-01`

## Questions

1. Does the previously selected analytical E-optimal observation remain useful
   when truth is generated by an independently implemented numerical
   advection-dispersion-decay solver?
2. Can the existing topology-oriented `rank_next_measurements` heuristic make
   an actionable transport sampling-time choice, and how does it compare with
   E-optimal, random, and oracle controls?

## Frozen design

- Truth generator: implicit finite-volume/upwind numerical solution of the 1-D
  advection-dispersion-decay equation implemented only in the benchmark script.
- Calibration model: production `TransportCalibrationAdapter` using the
  HydroSheaf analytical solution.
- Truth: dispersivity 2.0 m and decay 0.005 d-1; distance 10 m; velocity 0.1
  m d-1; source concentration 1.0.
- Base times: 150, 180, 210 d. Candidate times: 50, 70, 90, 105, 120, 150,
  180, 240 d.
- Numerical grid check: 120, 240 and 480 cells at 0.05 d time steps. The
  240-cell truth is accepted when its maximum difference from 480 cells is no
  more than 0.25 declared observation standard deviations.
- Oracle selection: candidate with minimum median joint log-parameter error on
  80 development replicates (seed family 2026072810), then frozen.
- Verification: 250 independent locked test replicates (seed family
  2026072820), paired across strategies.
- Strategies: no new observation, analytical E-optimal, fixed development
  oracle, and replicate-wise random.
- Existing heuristic portability test: candidate times are supplied as opaque
  candidate IDs with otherwise identical categorical evidence. It is
  actionable only if the returned recommendation identifies a transport
  concentration sampling time with a non-tied priority. No ad hoc translation
  from age/isotope/topology recommendations is permitted.
- Uncertainty: 5,000 paired bootstrap resamples.

## Decision rules

Independent-model robustness is supported only if the numerical convergence
gate passes and the E-optimal strategy has strictly negative 95% paired
bootstrap intervals for both dispersivity and decay absolute log10 error versus
no new observation.

The existing active-learning heuristic is supported for transport design only
if it produces an actionable, non-tied candidate-time recommendation and its
locked-test joint error is no worse than random. If it cannot express the
decision, report `NOT_ACTIONABLE_FOR_TRANSPORT_TIME_SELECTION`; do not silently
map its categorical recommendation to a sampling time.

All conclusions remain controlled-synthetic and model-class bounded.

## Exclusions

Temporal-series, three-dimensional, and vadose capabilities are not evaluated.
