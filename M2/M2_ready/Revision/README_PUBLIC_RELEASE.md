# Public source-only M2 revision package

This directory contains the revised M2 manuscript package, the clean and
coloured DOCX outputs, the revised Supplementary Information, the response
letter, the locked numerical audit, supporting tables and figures, and the
small source/result files needed to identify the reported values.

The underlying local analysis history is referenced as commit `463e1ce` on
`codex/m3-correctness`. That historical commit is not used as the public base
because its unpublished history contains oversized `M4/data` Git blobs. The
public branch is a source-only derivative based on the already-public
`codex/m3-correctness-source-publish` snapshot. The final reproducibility
manifest records the public release snapshot commit and its file checksums.

The reviewer comment file, submitted PDF, tracked-change working copies,
stale backups, and rendering-QA folders are intentionally excluded from this
public package. Raw ignored field-input files are also not redistributed here;
the locked field result tables and the documented external data sources remain
identified in the manuscript and audit files.
